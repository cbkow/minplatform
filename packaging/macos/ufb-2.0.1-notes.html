UFB 2 is the same tool, rebuilt from the ground up: a file browser first, with the job tracking you know. It opens your database where it is (one copy is kept beside it) and takes over your bookmarks, project folders, path mappings and sync settings.

  • A file browser that works like one — a second pane, optional tabs, drag and drop, the system's Trash, and Undo / Redo for file operations.
  • A tasks panel for copies, archives and transcodes; archives are read by UFB itself (zip, 7z, tar; rar through the system's tool), with passwords.
  • A Settings window: what a pane shows, start at sign-in, sync, path mappings.
  • Project types a studio can write itself; several rows of the tracker and several cards of the board at once; notes on several lines; rename several files in one step.
  • Shares are the system's own mounts, saved in the sidebar and connected on a press.

What is gone — sync mounts with their local cache, the mount agent and the Finder extension. A sync mount saved in 1.4 becomes a plain saved share. The installer removes the old /Applications/UFB folder and installs /Applications/UFB.app.

Mixed studios — UFB 2 and 1.4 machines share metadata, but columns made on a UFB 2 machine do not appear on machines still on 1.4: move a studio's machines together. macOS 13 or later is required. Read Upgrading from 1.4 first.

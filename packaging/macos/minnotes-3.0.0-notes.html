• minNotes 3 is a new application under the same name. A document is now a collection of notes, folders and canvases. A minNotes 2 document is imported, not opened in place: open it and choose Import. The old file is not changed; things placed directly on its canvas, outside a page, are not imported.
  • Folders, a merging save for shared storage, video notes and drawings in the note, a large view for PDFs and pictures, tables as boards, Web Folder export with an optional password, packages, and a wider import.
  • Windows: minNotes comes from the Microsoft Store only, which also delivers its updates.

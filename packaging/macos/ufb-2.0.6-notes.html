• Windows: a share that would not connect (1202). A drive letter that Windows still remembers for another share is no longer chosen for a new one; UFB takes the next free letter.
  • A share that cannot be connected says why in the log.

From 2.0.5:

  • Links you can press. A link in a Links column opens when it is pressed: a web page in the browser, an application's own address in that application. Pressing the rest of the cell edits it, as before.
  • Web links as files. New Web Link… in a folder's menu makes a link file from an address (the clipboard's, when it holds one). Opening a link file opens its address.
  • New minNote… in a folder's menu makes a dated minNotes file and opens it.
  • New UFB Folder…, New Date Folder and New Time Folder are back in a folder's menu.
  • Double-click is a choice. Settings → General: a double click previews a file, or opens it in its application. Space previews either way.

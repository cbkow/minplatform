minRender 1.0.3

  • A node restarted during a render comes back. Restart App in a peer's menu, Save in Settings and Exit, used while the node was rendering, took the node off the farm but let the render run to the end of its chunk; after a restart the node then did not come back. The render is now ended at once and the node starts again.
  • Windows: the window is no longer dim on an HDR screen. It follows the screen's SDR brightness.

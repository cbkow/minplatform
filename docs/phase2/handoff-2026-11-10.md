## Things that bite

- `packaging/macos/make-app.sh` is a **zsh** script (`zsh packaging/macos/make-app.sh`). It overwrites the bundle's binary:
  run it only when no QCView from `target/dist` is running, or the window on screen is the old build.
- The Windows notices are generated on the Mac and committed with a `.check` sidecar. After any change to `Cargo.lock`, the
  app version, `components.json` or `vcpkg-windows.pin`: regenerate (`python3 packaging/notices/make_notices.py windows --out
  packaging/notices/generated/THIRD-PARTY-NOTICES-windows.html`) and commit BEFORE packing on the box.
- Signing a sideload copy must run in the box's desktop session, never over plain SSH.
- A subagent's spec is a reading, not a run: its "verified in code" lines were not re-checked unless this page says so.

`main` is ahead of origin and unpushed (the user pushes).
